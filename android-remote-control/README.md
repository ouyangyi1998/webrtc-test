# Android 远程控制客户端

基于 WebRTC 的 Android 被控程序，将手机屏幕实时共享到 Web 端，并支持远程控制。

## ✨ 特性

### 核心功能
- **实时屏幕共享**：WebRTC 低延迟推流
- **远程控制**：点击、滑动、双击、长按
- **键盘输入**：通过无障碍服务注入文本
- **快捷键映射**：返回、主页、最近应用
- **前台服务**：保持共享稳定运行

### 网络稳定性
- **WiFi/4G 无缝切换**：NetworkMonitor 快速感知，<5s 恢复
- **智能防抖**：网络丢失 500ms 防抖，peer-left 3s 延迟处理
- **ICE 自动重启**：最多 3 次重试，自动恢复 P2P 连接

### 性能优化
- **硬件编码优先**：H.264 High Profile + VP8/VP9 硬件加速
- **SVC 分层编码**：L1T1/L1T2/L1T3 动态切换，弱网更流畅
- **分辨率自适应**：根据码率自动缩放 (1080p → 720p → 540p → 360p)
- **关键帧请求**：画面卡顿时自动请求 I 帧

## 📋 系统要求

- Android 7.0 (API 24) 及以上
- 构建环境：Java 17+, Gradle 8.5+

## 🚀 快速开始

### 1. 构建 APK

```bash
cd android-remote-control
./gradlew assembleDebug
```

APK 位置：`app/build/outputs/apk/debug/app-debug.apk`

### 2. 配置权限

安装后需启用以下权限：

| 权限 | 路径 | 说明 |
|------|------|------|
| **无障碍服务** | 设置 → 无障碍 → 远程控制服务 | 用于注入手势和文本 |
| **悬浮窗** | 设置 → 应用 → 特殊权限 → 显示在其他应用上层 | 用于显示状态 |
| **屏幕录制** | 启动时弹窗授权 | 用于捕获屏幕 |

### 3. 使用

1. 确保信令服务器已启动
2. 打开 App，配置服务器地址和房间号
3. 点击「启动连接」，授权屏幕录制
4. 在 Web 端进入相同房间即可查看和控制

### 鼠标 → 手势

| Web 端操作 | Android 执行 |
|-----------|-------------|
| 左键单击 | 点击 |
| 左键双击 | 双击 |
| 右键 | 长按 |
| 拖动 | 滑动手势 |
| 滚轮 | 滚动 |

### 键盘 → 按键/手势

| 按键 | Android 操作 |
|------|-------------|
| **Escape** | 返回 (Back) |
| **Meta+H** / **Home** | 主页 |
| **Meta+Tab** | 最近应用 |
| **Backspace** | 删除字符 |
| **Enter** | 确认 |
| **其他字符** | 文本注入 |

## ❓ 常见问题

### 1. 无法注入手势/文本
**原因**：无障碍服务未启用  
**解决**：设置 → 无障碍 → 远程控制服务 → 启用

### 2. 屏幕共享黑屏
**原因**：屏幕录制权限被拒绝或 MediaProjection 失效  
**解决**：重新启动连接，在弹窗中授权

### 3. 连接频繁断开
**原因**：系统杀死后台服务  
**解决**：
- 在电池优化中将 App 设为「无限制」
- App 会自动尝试重连

### 4. 画面卡顿
**原因**：网络带宽不足  
**解决**：在 Web 端切换到「流畅」模式
